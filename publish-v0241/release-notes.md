v0.2.41 歷史資料核對與背景程序結束修正（測試版）

• 加權指數近期日線會與證交所七個月完整月報核對。休市空白列經核實才排除；官方有交易資料時補入指數收盤。股票未還原價格不混入還原股價，未知缺值仍保留。
• 興櫃前日均價不再與前一日最後成交價混比。盤中可用最新成交建立暫估；一般股票前收異常時保留已完成日線統計，不再整塊停算。歷史類比仍非預測勝率。
• 期貨分析補查最多 24 個工作日的同契約官方日線，使用單獨快取，30 分鐘內不重複請求。近、次月分開，不拼接不同契約。剛掛牌的次月契約仍可能沒有 20 筆，長線繼續明確使用適用標的環境。
• 背景更新工作目錄移至 LocalAppData，啟動器工作目錄移至 TEMP。正常結束會等待並清理本程式啟動的更新子程序。更新子程序加入具有 KILL_ON_JOB_CLOSE 的 Windows Job；主程序被關閉時由 Windows 清理所屬子程序，不掃描或強制結束其他 PowerShell。
• 舊版已留下的程序不會被新版任意終止。可在工作管理員「詳細資料」顯示「命令列」，只結束命令列含該舊版完整資料夾路徑及 Update-Manager.ps1 的 powershell.exe，再刪除資料夾；請勿全部結束 PowerShell。
• 實際 Yahoo 加權指數、6748 興櫃與證交所 2026/10 月報已重現並驗證修正。來源可有真正缺漏、限流或暫時失敗，公開資料不等於每個介面每次都能成功回傳。
• 保留前版 AI 新聞彩色摘要、警報、設定備份、圖表拖移與更新驗證。此包不推送為正式自動更新；Windows 關窗與刪除資料夾仍需在 Windows 實機驗收，本環境只完成 PowerShell 語法、C# 編譯與自動化回歸。
