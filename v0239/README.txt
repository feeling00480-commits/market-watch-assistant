看盤小助手 v0.2.39｜Windows 免安裝版
========================================

啟動
1. 把 ZIP 完整解壓縮到同一個資料夾。
2. 雙擊 Start-One-Click.cmd。保留啟動視窗和瀏覽器頁面。
3. 頁面預設追蹤加權指數和台指期。按「開始監控」才會定時檢查警報。
4. 結束時在「設定」按「結束看盤小助手」，或關閉啟動視窗。
   若瀏覽器沒有自行開啟，可複製啟動視窗顯示的完整網址。網址只供這次本機工作階段使用。

一鍵啟動
• Start-One-Click.cmd 會先核對本版 Start-Server.ps1 與 app.html 的 SHA-256。請從可信來源下載完整 ZIP。若檔案缺失或內容不符，啟動器會停止。
• 在沒有 PowerShell 群組原則管理的電腦上，啟動器使用當次程序的 RemoteSigned。若已核對的 Start-Server.ps1 有下載標記，會移除這一個檔案的標記。不改動目前帳號或整台電腦的持續性政策。
• 有群組原則時依原本政策啟動。若政策限制指令碼或要求簽章，會停止並在啟動視窗顯示原因。Start-Market-Watch.cmd 也會轉至相同的一鍵啟動流程。

使用條件
• 使用 Windows 內建 Windows PowerShell 5.1 和新版 Edge／Chrome。公司政策須允許執行 PowerShell 指令碼、使用 localhost 及連線到需要的行情或通知服務。
• app.html 由本機服務載入。直接雙擊 app.html 只會顯示啟動說明。
• 正常使用以一般帳號啟動。如果一鍵啟動仍顯示群組原則限制、應用程式被原則封鎖，或無法開啟 localhost，請查看啟動視窗中的錯誤訊息。
• 使用與 v0.2.11 相同的瀏覽器設定檔和 localhost 連接埠，可沿用自選股與規則。啟動新版前先結束舊版，讓預設連接埠 18888 空出。
• 重大警報觸發時，本機服務會在 Windows 主螢幕的右下角顯示約 8 秒，可在瀏覽器縮小時看到。桌面視窗出現時不會主動切走目前的視窗焦點。桌面提示送不出時，右欄會留紀錄。網頁本身以監控動態更新。
• 行情檢查仍由看盤頁面計時，請保留看盤頁面與啟動視窗。背景分頁可能被節流或休眠，回到頁面時會補做逾期的檢查。關閉頁面後會停止監控。

v0.2.39 短線／波段／長線觀察（測試版）

• 名稱旁加入小字商品代號。一般台股技術數據、評分依據、營收與估值移入預設收起的「查看技術與基本面數據」。雷達移到新觀察區下方。
• 加入 5、20、120 交易日歷史類比統計。依每個商品自身相似價格型態的到期漲跌比例顯示，不是 AI 編造的數字，也不是經校準的預測機率。
• 正常交易時段收到有效新報價就重新比對；即時價格作為當日暫時收盤價。尚未用歷史同時段資料驗證盤中準確性，不可解讀成即時勝率。新價格未改變類比樣本時，比例可以維持原值。
• Yahoo Finance 還原日收盤價最多保留近 30 年。每天分盤中／收盤讀取，成功後最長快取 6 小時，失敗 10 分鐘後再試。延遲、過期或時段外報價沿用完整日 K。前收不一致時暫停盤中估計。
• 目前使用價格衍生的月／季均線距離、5 日動能與 RSI。營收、法人、新聞、成交量尚未納入數字；既有功能塊仍獨立提供這些資料與評語。
• 先取距離最近的四分之一候選，再取最多 30 筆互不重疊的後續期間。少於 12 筆不顯示比例；12 筆只是最低顯示門檻，不代表統計足夠可靠。
• 持平範圍：5 日 ±1%、20 日 ±3%、120 日 ±5%。比較第 N 個交易日的還原收盤價與起點，不是期間內觸及目標的機率。未計手續費、稅、滑價。
• 每張卡片可查看上次變化、樣本起點範圍、Wilson 區間與按時間向前的 Brier 診斷／歷史基準。區間未涵蓋市場結構變化與模型偏差，診斷未證明穩定預測優勢。
• 來源的空白週末記錄不列為交易日；未知工作日缺值保留斷點，剔除跨越斷點的特徵與未來窗口。不重疊樣本仍可能受同一市場循環影響，並不保證統計獨立。
• 台股、ETF、指數、美股與有足夠資料的興櫃各用自己的歷史。期貨不強套此類比，保留原有分析。來源缺資料或樣本不足時顯示原因，不使用示範百分比。
• 不呼叫 Gemini，不新增自動買賣警報。原有目標、停損、急漲跌與異常量警報維持。
• 沿用 v0.2.38 共用設定、歷史備份、自動更新與 Windows 桌面小窗。先關閉舊版服務，解壓到新資料夾，執行 Start-One-Click.cmd。
• 基於可核對的 GitHub v0.2.38。截圖中的「PC 共用快取／今日共用 AI」未在該版原始碼中，此包不含額外的共用服務；請保留目前版本以便比較。本測試包不推送為自動更新正式版。
• 自動化檢查不等於 Windows 實機驗證。首次啟用請先用設定內的桌面警報測試確認。


v0.2.38 使用者設定備份與自動更新
• 設定 → 備份與更新提供立即備份、匯出 JSON、匯入預覽、歷史備份還原。
• 預設在設定變更後約一秒內寫入檔案，並每 5 分鐘補查未備份的變更。可改為 1、5、15、30、60 分鐘，或停用自動備份。需保留頁面與啟動視窗，背景分頁仍可能被瀏覽器節流。
• 共用設定位置為 %LOCALAPPDATA%\MarketWatchAssistant\UserData\Settings。保留最近 30 份歷史檔。若系統無法提供 LocalAppData，才使用程式內 UserData，實際位置顯示在設定頁面。
• 新版本啟動時會先讀取共用設定，保留自選股、成本、張數、目標、停損、警報門檻、排序、釘選與外觀／圖表偏好。開始監控仍需自行按下。
• 第一次移轉請使用舊版相同的瀏覽器設定檔與本機網址，讓本版讀到原本設定並建立第一份檔案備份。完成後其他版本、不同連接埠或瀏覽器可讀取共用設定。跨電腦請匯出、匯入 JSON。
• 瀏覽器與檔案設定衝突且無法判定新舊時會保留兩份，請在備份頁面選擇。偵測其他視窗寫入時會停止覆寫。主檔損壞時嘗試最近有效歷史備份，較新格式不會被舊版覆蓋。
• 備份不含 AI 或 Telegram 金鑰、行情快取、警報紀錄、分價逐筆檔與 AI 分析文字。AI-Analysis 仍在程式資料夾，搬移至另一個資料夾時請自行一併保留。
• 更新主來源預設 feeling00480-commits/market-watch-assistant 的公開 GitHub Releases。發版區未建立或尚無正式版時會顯示原因，其他功能照常使用。
• 本機服務在頁面完成啟動後每天檢查一次。失敗時至少等待一小時再試，來源限流或離線不影響現有版本。可在備份頁面立即檢查、下載。
• 預設新版下載備用，通過固定 GitHub 來源、ZIP SHA-256、必要檔案清單與逐檔 SHA-256 驗證，結束程式後下次啟動自動套用。更新不會強制中斷盤中、夜盤或美股監控。
• 前一版程式保留在 Previous-Version。若新版未回報完成啟動，下次啟動時嘗試驗證並還原前一版。更新失敗版本會停止自動重試，可手動下載重試。
• HTTPS 與來源／雜湊驗證不等同 Windows Authenticode 程式碼簽章。本包仍為未簽署的 PowerShell 程式。
• 已以 Node 與 PowerShell 執行設定與更新檔測試；仍需在 Windows 確認啟動、桌面警報與真實 GitHub 跨版本更新。

v0.2.37 股票搜尋與市場校正
• 補上上市、上櫃及興櫃公司名稱資料備援，支援不同來源的中英文欄位與 CSV。
• 任一市場清單失敗時會顯示缺漏市場，可按「重新載入清單」。不完整清單一分鐘後可再嘗試，不再當成完整清單快取六小時。
• 不認得的數字代號會查詢上市與上櫃的單檔名稱及市場，不再直接假設為上市。無法驗證時不提供錯誤市場的加入選項。
• 成功取得的名稱索引會保留最多七天，供來源短暫失敗時使用。實際行情仍需網路及上游服務正常。
• 開啟新版及股票搜尋時，會依取得的名稱索引校正既有追蹤商品。若原本市場分類錯誤，會重抓行情並移除舊市場的暫存資料。持股成本、目標、停損、釘選與自訂排序保留。
• 股票可用代號或公司簡稱搜尋。3227 應顯示原相與上櫃；美股明確指定可使用 US:代號，期貨可使用台指期、小台、微台等名稱。
• 驗證包含多檔股票、來源失敗、快取重試、既有持股資料保留及非同步搜尋。此環境無法執行 Windows 桌面視窗與上游即時連線測試。

v0.2.36 價位警報判定
• 成本參考價只在接近、觸及或相鄰報價跨越時提醒。價格遠低於成本時，不會標示為到達成本。
• 停損、目標與進場價提醒會標示觸及、已低於或已高於，避免把超過設定價位寫成剛好成交。
• 修正冷卻期間出現的新異常，冷卻結束後仍符合條件時可以提醒。主要成交密集區警報同樣處理。
• 過期內外盤分類資料不再用於買賣偏向警報。

v0.2.35 圖表左右平移
• 在主圖或技術指標圖按住滑鼠左鍵左右拖曳，可保持目前尺度瀏覽前後資料。拖曳到圖外放開也會結束拖曳。
• 日／週／月 K 拖到較早位置時，會按原本支援範圍補載歷史資料。平移以已取得的資料為限。
• 按「重設視圖」可回到預設的最近區間。

v0.2.34 桌面警報外觀
• 重大警報顯示在 Windows 主螢幕右下角。小窗沿用「設定 → 外觀個人化」已儲存的主題與顏色。
• 設定 → 測試警報彈窗可直接測試。失敗原因顯示在設定測試區及監控動態。
• 桌面小窗逐筆顯示。佇列已滿時，後續警報仍列在監控動態。

v0.2.33 警報彈窗
• 重大警報同時顯示於頁面右上角並嘗試送到 Windows 桌面。頁面提示會顯示桌面通道或失敗原因。
• Windows 桌面小窗短時間收到多筆警報時會排隊，待前一筆關閉再顯示。隊列滿時交給 Windows 通知備援。
• 設定 → 測試警報彈窗可直接測試，無需開啟行情監控。

v0.2.32 目前版本

v0.2.31 台股 ETF 與加權指數專屬分析
• ETF 分析列出重點摘要、價量、均線、日線動能、基金法人交易與持倉試算，並依日期對齊收盤價比較 ETF 和加權指數近 5／20 個交易日的漲跌。此比較未含配息。
• 大盤分析列出重點摘要、指數趨勢與動能，以及證交所盤後上市股票漲跌家數、全市場成交金額與上市三大法人淨額。各段標示來源日期，交易日資料暫缺時等待官方公布。
• 台股 ETF 與加權指數移除公司財務分頁。ETF 的法人籌碼仍可查看，個股保留公司研究雷達。

v0.2.30 美股、興櫃分析與四市場警報
• 美股市場總覽提供開盤至今變動、日內位置、SPY／QQQ 比較、成交量與均線；美元行情列近 10 個交易日日行情。美股警報限美東一般盤及有效新報價。
• 興櫃總覽加入價量、日內位置、均線、營收與可驗證的雙邊價差；成交明細列近 10 個交易日日行情。
• 四種市場皆支援接近／觸及停損、目標及進場價和漲跌警報。新增近期急漲急跌與成交速度突增。期貨按契約及日夜盤分開；興櫃可設定報價價差；台股個股可選擇以新增內外盤資料判定放量偏向。
• 量能警報需要同一來源、同時段的多筆成交量樣本。量能不足時等待有效資料。美股、期貨與興櫃的放量訊息分開寫價格方向。
• 既有規則會保留。已有追蹤的商品可在「監控設定」填入新門檻，或套用預設後儲存。需開啟監控才會推送。

v0.2.29 期貨分析重點標註
• 合約總覽將日夜盤差異、漲跌幅、價差及外資淨部位以彩色粗體標示。沿用紅漲綠跌，跨時點比較以琥珀色提醒。
• 盤後部位分開標示外資目前淨部位與較前次的變化。例如目前淨空、空單淨部位縮小時，兩個重點以不同顏色呈現。

v0.2.28 期貨分析與盤後籌碼
• 圖上保留一句走勢摘要；合約總覽補上日夜盤落差、期現貨與近次月價差的解讀。日夜盤只有在同一交易循環時才直接比較。
• 盤後部位先看外資及陸資多單、空單、淨部位與前次變化，再看其他法人和近 10 次淨部位圖。法人資料依商品統計所有月份，與近月、次月的行情分開。
• 大台、小台、微台提供並列口數、小台與微台散戶多空比估算、台指選擇權全市場 Put/Call 未平倉比、前五大及前十大交易人和上市現貨法人買賣超。各項標示報表日期，來源為期交所或證交所。
• 散戶數字是全市場未平倉減去三大法人後的估算，包含其他非法人部位。前五大、前十大按買賣方各自排名，並按期交所的口徑換算大台口數。
• 臺指 VIX、週三／週五選擇權分項、外資買權與賣權分列留倉需另行確認一致的公開資料來源。

v0.2.27 商品介面與桌面警報
• 選到期貨、美股、興櫃時，自動切換到各自的行情卡和分頁。台股原有版面與全商品共用自選清單保留。
• 期貨顯示契約月份、最近公布結算價、近次月成交量與兩種價差。日夜盤圖表切換只影響顯示，設定警報請用「契約與警報設定」。盤後部位顯示同契約未平倉量。
• 美股顯示美元、一般盤與美東時間，盤前盤後尚未接入。興櫃分開顯示成交資料與來源買賣報價，只有取得同筆有效雙邊報價才計算價差。
• 桌面小窗採用深色圓角與淡藍色，商品、價格與觸發原因分開顯示。Windows 通知備援由系統管理外觀。預覽入口在「設定 → 測試模式」。

v0.2.26 期貨分價
• 開啟期貨分價圖會自動讀取期交所近 30 個交易日的公開下載清單，依選取期間補載已公布的 ZIP，按商品和契約月份統計成交價帶。初次會逐日顯示進度。
• 已取得的價量彙總會快取在目前瀏覽器與連接埠。同日官方檔案更新後會重新下載。歷史區間顯示實際取得天數，未湊足時會保留已取得的官方資料。
• 正在進行的日盤或夜盤仍使用「分 K 估算」。已公布的資料會標示「期交所官方逐筆」，並列出涵蓋的日夜盤。手動 CSV 匯入保留為備援。

v0.2.25 更新
• 分價圖左側顯示成交量分布，右側用虛線連接最新價、最大成交價帶、可能壓力與支撐，並把情境評語放在右上。分價圖與走勢圖共用圖板高度。可按 ＋／− 或在分價圖上滾動縮放，「全圖」會回到完整價格範圍。
• 左側「自訂排序」可拖曳手把，或選取手把按上下方向鍵。每檔都能釘選，釘選項目在所有排序中固定於上方。順序與釘選會儲存於目前瀏覽器。
• 期貨日盤與夜盤分開判定警報，夜盤跨午夜沿用同一時段。美股使用一般交易時段報價。開啟監控並收到有效新報價後才會判定。延遲與盤後備援報價不會觸發。
• 桌面小窗建立失敗時會改交給 Windows 通知，並在啟動視窗記下錯誤。請在「設定 → 測試模式 → 預覽桌面通知」確認。若監控動態顯示已交給 Windows 通知，可在通知中心查看。

行情功能
• 「設定 → 檢查間隔 → 最快（依來源）」保留原有固定間隔，也可按來源各自排程。證交所 MIS（上市／上櫃）每 10 秒批次檢查，Yahoo 台灣期貨 15 秒，Yahoo Finance 美股 30 秒，興櫃 60 秒。這是程式檢查頻率，上游可能沿用前筆報價。已知延遲、盤後備援或過時行情不作為盤中警報。來源限流時暫停重試。
• 主圖新增「分價圖」，可切換當日、5／20／30 個交易日。上方顯示一句話，並標出最大成交價帶、現價及上、下方成交密集區。分 K 估算將成交量分配到高低價涵蓋的價帶，圖上列出實際資料日期與天數。加權指數本身沒有可按指數價位累計的成交量。
• 期貨逐筆資料依商品與契約月份分開，成交量以口顯示。若要手動匯入，從期交所下載 ZIP、解壓後在圖表內一次選取多日 CSV。手動匯入的資料保留於本次開啟期間。未取得可用逐筆或分 K 資料時，圖表會標示資料不足。
• 個別商品的「設定警報」新增主要成交密集區突破／跌破提醒，預設關閉。依前 20 個交易日資料建立價帶，兩筆連續新價跨出後記錄於監控動態，啟用 Telegram 時也會以靜音傳送。
• 期貨的「分析」左框顯示日夜盤區間、漲跌、成交量、次月與近月價差及同月份的未平倉量變化。大台、小台、微台可看期現貨價差。現貨收盤後以明確日期的現貨收盤價作參考。AI 摘要可引用這些期貨欄位。未平倉量採報表公布值，法人部位尚未接入。

行情、研究與憑證
• 分時圖混合有來源標籤的歷史分時及程式執行期間取得的 MIS 快照。1／5／30／60 分 K 使用來源提供的 OHLC。30／60 分 K 以近一個月的 15 分 K 資料彙總，並以可用的當日分 K 補上更新時段。台指期只使用現有分 K 行情。若上游只提供較粗的週期或缺資料，顯示缺資料。週／月 K 由日行情彙總。
• 台指期近月與次月從 Yahoo 股市取得。報價標籤依來源回傳時間判斷日盤或夜盤，走勢與最新報價時間可能不同步。期交所備援資料是日盤資料。台股可看到一般收盤行情，目前未另抓盤後定價或盤後零股的成交明細。
• 技術圖支援 MA5／10／20／60、成交量、KD、MACD、RSI 與十字游標。歷史選項會依供應商實際可提供的範圍顯示，台指期只取近數個交易日同契約資料。分時更新依監控間隔與上游報價，不是逐筆行情。
• 圖表右上角的週期與歷史範圍共用於全部股票。切換股票會沿用上次選擇，同一個瀏覽器與本機連接埠會記住設定。
• 開始或重新開始監控後，每檔收到第一筆有效報價就檢查交易計畫。報價觸及或低於停損價、觸及或高於目標價、降至進場價都會提醒。未填進場價時，平均成本只在接近、觸及或相鄰報價跨越時提醒。
• 接近目標的價差以目標價為分母，預設 1%，可在個股設定自訂。填 0 只關閉接近預警。預警與到價分開觸發，持續在同一目標區間時不反覆通知。
• 桌面版左欄和主圖從頁首開始，監控按鈕、設定與監控動態保留在右欄。
• 內外盤只在走勢圖顯示，使用 Yahoo 股市公布的成交張數、比例與資料時間。任一側達 55% 顯示較多，報價與分類資料相差兩分鐘以內時，會補充價格方向是否一致。窄視窗放在走勢圖下方。來源缺值時會標示。
• 可用名稱或代號找興櫃，也可輸入「興櫃 7796」。行情依來源發布時間更新，分析使用可取得的 K 線與公開月營收。
• 輸入 AAPL、NVDA、SPY 等美股代號可查報價與 K 線，價格以美元、交易量以股顯示。報價時效以來源為準，分析使用適用的技術資料。
• 「走勢圖」及各週期 K 線可用滑鼠滾輪連續縮放。放大時依序可由日 K 接到 60／30／5／1 分 K，縮小時按反方向切換，並盡量保留游標附近的時間。來源需有對應日期的分 K。放大時會限制 K 棒間距，資料少時仍保持緊湊。拉遠時依實際跨度提示 1 個月、1 季、半年、1 年，最多顯示最近一年可取得的歷史資料。游標在圖表或技術指標圖內時，到達縮放邊界也會保留滾輪操作，不帶動畫面上下捲動。十字游標會在右軸顯示價格、在下軸顯示日期或時間。重設縮放可回到原範圍。
• 技術、籌碼及財務區塊的評語採紅色偏多、綠色偏弱、灰色持平或資料不足。雷達旁列出具體命中條件，條件可能重疊。
• 「籌碼」提供上市與上櫃最近最多 10 個交易日的三大法人買賣超，單位為股。雷達使用最近 3 份有連續資料的日報檢查買賣超。
• 「財務」提供最近 12 個申報月份的營收、年增及月增。歷史資料由公開資訊觀測站取得，缺月顯示空白。營收評語同時說明年增與月增，年增率的正負優先於月增率。
• 左欄保留名稱、價格和漲跌幅，再用一句話描述盤中或收盤。收盤優先顯示自訂風險價位、放量方向或漲跌強弱，並選擇已確認的均線穿越、同日大盤差距、日內區間位置或均線位置補充。跨日報價會標示日期，缺少資料時只使用已有行情。
• 上方可切換走勢圖、K 線和分價圖。下方切換「分析／新聞／行情明細」不會影響上方圖表。分析區填滿可用寬度，左、右等分，兩個外框等高。股票左框放研究雷達、評分、基本面與持倉試算，期貨左框放期貨分析，右框放 AI 摘要。AI 長文只在右框內捲動，分析按鈕與紀錄選單固定在框頂。視窗較窄時改為上下排列。五檔、報價明細和 KD／MACD／RSI 在「行情明細」。
• 右欄顯示最近一輪的成功、時效、缺漏及各檔最新動態。監控紀錄保留在開啟中的頁面。
• 「設定 → 外觀 → 個人化」可調整深色主題、背景、文字、強調色、字級與對比。預覽後按「儲存外觀」。外觀儲存在同一瀏覽器及本機連接埠。
• 「分析」可看不需 AI 的研究雷達。趨勢、動能、量價由行情算出，營收與估值使用公開資料。上市顯示本益比、股價淨值比與殖利率，上櫃本版只接月營收。ETF、期貨、指數及缺值按資料可用性顯示。未提供同業估值、籌碼、除權息事件或完整財報品質分析。
• 技術面標籤依日 K 趨勢與動能分開判定。兩項皆偏強才顯示紅色偏多，兩項皆偏弱才顯示綠色偏空。標籤下方列出評估日期、均線、RSI 和 MACD 柱。
• 盤中使用有效估算量比。收盤後使用交易所日 K 的成交量與前 20 個交易日均量比較，並列出日期、來源和收盤漲跌。當天日 K 尚未發布時，使用最近可取得的有效交易日並標明日期。
• 點選雷達圖的項目名稱或分數可在圖下看到一行解釋。
• 研究雷達圖在左框置中。研究區用顏色標出偏正向、承壓與營收變動。AI 新舊紀錄會將 Markdown 標題、清單及粗體轉為排版，原備份仍是純文字。
• AI 摘要會依所附資料整理公司近況、買賣盤／量價、風險、買進及賣出與續抱條件。缺少或過時的資料應標出，觀察價位須附依據。
• 「設定持倉／試算」可填成本、張數、計畫進場價、目標價、停損與虧損預算。填足資料後，研究區會顯示目前估算損益、停損及目標價情境、理論進場股數上限，以及持倉超出風險預算的情境股數。未計手續費、稅及滑價。
• 「納入持倉與交易計畫」預設未勾選，勾選後才會隨此次 AI 請求或複製文字附上持倉。勾選後的 AI 回覆可能包含私人持倉，會隨分析文字在本機備份。
• 雷達分數由固定規則計算。若要移植到 GAS，可沿用指標和評分公式，再由網頁畫圖。此 ZIP 為 PC 版。
• 瀏覽器只連線到本機服務，服務轉送到程式列出的行情及官方 API。開啟外部新聞、ChatGPT 或 Gemini 網站是個別使用者操作。
• Telegram 需要自己的 Bot Token 和 Chat ID。Token 只供本次本機服務使用。停用或結束即解除設定。AI Key 每次分析時重新輸入。程式不把這些金鑰寫入瀏覽器儲存或設定檔。
• Gemini Flash-Lite（預設）可在 https://aistudio.google.com/apikey 建立金鑰，使用符合免費方案的專案。Groq GPT-OSS 可在 https://console.groq.com/keys 建立金鑰，受免費方案額度限制。OpenAI API 可在 https://platform.openai.com/api-keys 建立金鑰，API 帳務與 ChatGPT 訂閱分開。
• Gemini 先使用本次輸入的金鑰查詢可用模型。若某個已列出的穩定 Flash-Lite 回傳 404，會嘗試清單內的另一個。權限或額度錯誤會直接顯示，不會改用其他模型重送。
• 成功的 API 分析會自動備份為 UTF-8 文字檔，位置是程式資料夾內的 AI-Analysis\股票代號。台指期近月、次月各自儲存。檔案包含分析結果、服務或模型與產生時間，沒有 API 金鑰。
• 分析右欄的「分析紀錄」會列出已存的紀錄。選取只讀本機檔案。按「重新分析」可另外送出新分析並留下舊檔。寫檔失敗時可在關閉前按「重新儲存」。
• 更換安裝資料夾或電腦時，可把整個 AI-Analysis 資料夾複製到新版的程式資料夾。v0.2.9 以前在頁面上看過但沒有手動保留的結果，不會出現在紀錄內。
• 還沒有金鑰時，可在 AI 分析內按「複製分析資料」與「開啟 Gemini 網頁」，在網頁手動貼上。若瀏覽器不允許自動複製，程式會顯示可選取的文字。剪貼簿內容依 Windows 設定可能留在歷程。

Windows 試跑順序
1. 用一般帳號啟動。確認本機頁面載入，更新加權及台指期，加入一支股票並切換分時、分 K、日／週／月 K，再開啟「分析」看研究雷達。
2. 設定 → 測試警報彈窗。確認 Windows 主螢幕右下角出現提示。若要測試縮小後的實際警報，按「開始監控」，保持頁面開啟並最小化瀏覽器。
3. 若需要 Telegram 或 AI，先在私人測試 Chat 或帳號驗證。禁用 Telegram 後再打開設定，確認 Token 欄為空白。按結束後，重新整理原網址應無法連到已關閉的本機服務。
