新增使用者設定檔案備份與自動更新機制。

- 設定 → 備份與更新提供立即備份、匯出、匯入與最近備份還原。
- 設定變更後自動備份，預設每 5 分鐘補查，保留最近 30 次備份。
- 新版與不同本機連接埠共用 Windows 使用者資料夾內的設定。保留持倉成本、張數、目標、停損、排序、釘選與介面設定。
- 每天檢查公開 GitHub 正式版，下載及 SHA-256 驗證後備用，下次啟動套用。
- 更新不覆蓋個人資料。前一版程式保存在 Previous-Version，新版未完成啟動時下次啟動嘗試還原。
- 本次移轉請使用原本的瀏覽器設定檔，先讓 v0.2.38 讀取並建立第一份備份。
- AI 與 Telegram 金鑰不包含在設定備份中。AI-Analysis 仍位於程式資料夾。

驗證涵蓋 89 項 Node、DOM 整合與 Linux PowerShell 設定／更新流程檢查；Windows 原生啟動與桌面小窗仍需實機確認。第一次移轉請先結束舊版，再用原本的瀏覽器設定檔開啟新版，建立第一份檔案備份。
